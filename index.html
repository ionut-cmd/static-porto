About

I'm a Staff Engineer at {{ site.author.company }}, working where AI agents, MCP and databases meet. Most days that means building MCP servers and clients that let LLMs call real tools and query real databases, designing event-driven agent pipelines that hand work from one stage to the next, and putting it all behind interfaces people actually want to use. My agents get exactly the permissions they need, which is usually fewer than they ask for.

Behind every confident LLM answer there should be a well-indexed table, so I spend a lot of time on the data side: ETL pipelines loading millions of records into PostgreSQL, parallel and idempotent ingestion, and messy public datasets turned into clean schemas, with enough XBRL parsing along the way to have opinions about accountants.

Lately that has included defence work: multi-agent simulations and AI decision-support tools where every recommendation has to show its evidence. Before that I worked on IoT security (device onboarding, SBOMs and vulnerability detection), and researched emotion-aware text-to-speech at the University of Surrey.

I like it when software meets hardware, too. I built a Holybro X650 quadcopter with a Raspberry Pi on top that sends it commands, wrote my own tool to read and debug its ESCs, and taught myself FreeCAD to design and 3D-print the parts it needed.

I'm usually the one who reads the 200-page spec so the rest of the team doesn't have to. Away from the keyboard you'll find me hiking, swimming, playing pool, spending time with my family, or starting yet another Raspberry Pi project.
